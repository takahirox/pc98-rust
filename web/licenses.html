The original Rust emulator, synthetic firmware, replacement Latin glyphs, browser host and Star Trail game are MIT licensed. No existing emulation library is used.

HelloWorld-PC98 by TakedaHiromasa is independently authored MIT boot software. The bundled floppy preserves only the upstream first 1024-byte boot sector, with all other bytes zeroed. Source commit: 4f1ea8e8d3196d4f2b53b17d9ac08e38d43df247. Original MIT notice.

The static app contains no DOS, NEC BIOS, NEC font ROM, proprietary disk images or external game assets. Optional FreeDOS(98) test media can be prepared from checksum-pinned GPL guest releases with the repository's preparation script, which also downloads matching complete sources and licenses. Those guests execute inside the emulator and are not emulator libraries. See docs/licenses.md in the source distribution for the file audit and source obligations.
