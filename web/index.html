PC-98 keyboard

Mouse or touch keys below, or focus the screen and use your physical keyboard. Shift, Ctrl, GRPH (Alt), XFER (right Alt), and NFER (left Meta) are supported.

PC-9821Ap starts with a writable 128 MiB FreeDOS HDD and empty floppies. Auto sends HDI to IDE HDD and supported floppy images to Floppy 1. Inserting floppies never reboots DOS. Boot from selects the next Reset; demo buttons explicitly boot Floppy 1. Eject and Export use the displayed drive. Reset retains writes; reload starts clean. Export and reinsert to save. HDD-booted DOS uses A: for the HDD, B: and C: for floppies. VM boots Floppy 1 and retains the HDD for returning to Ap. Replacing an HDD resets the machine; Restore FreeDOS HDD replaces it with a clean copy. Changes stay in memory, with no upload or automatic storage.

Compatibility is limited to the documented CPU/device subsets. Ap adds Japanese CG, 16/256-color video, approximate FM/86 PCM, IDE and bus mouse input. INT 33h requires a guest DOS mouse driver. Ap supports bounded ring-0 protected mode, 4 KiB paging and VM86; DPMI, privilege transitions and numerical FPU execution remain unsupported.
