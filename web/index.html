PC-98 keyboard

Mouse or touch keys below, or focus the screen and use your physical keyboard. Shift, Ctrl, GRPH (Alt), XFER (right Alt), and NFER (left Meta) are supported.

Drop a supported floppy onto the screen to insert and boot it. Bootable PC-98 media required; compatibility is limited to the documented CPU and device subsets. The Ap DOS profile adds replacement Japanese CG, 16/256-color graphics and approximate FM/86 PCM sound. Ap also supports an IDE HDD and a bus mouse. Guest software must support these devices; mouse use through INT 33h requires a guest DOS driver. Ap supports a bounded paging-disabled ring-0 protected mode; paging, DPMI and privilege transitions remain unsupported.
